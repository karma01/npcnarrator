Privacy Policy: Clips Uploader

Last updated: 18 November 2026

Clips Uploader is a private desktop tool used only by the owner of the NPC Narrator YouTube channel to upload that channel's own Shorts. It has no other users and no public sign up.

What it accesses

Through the YouTube Data API, with the owner's permission, the tool can upload videos to the owner's channel (youtube.upload) and read that channel's basic details, such as its name and its own videos (youtube.readonly).

How data is used and stored

  • The sign-in token is stored only on the owner's own computer and is used only to upload and check the owner's own videos.
  • No data is sold, shared with third parties, used for advertising, or sent to any server other than Google's YouTube API.
  • The tool does not collect data about viewers or other YouTube users.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer removes all stored data.

Google policies

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Its use of information from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact through the NPC Narrator YouTube channel's About page.
